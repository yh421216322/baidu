游戏核心代码流转可视化

流程一：玩家开始科技研究

  • TechDisplayItem.cs (UI项)
    • 用户点击 "研究" 按钮，触发 `HandleResearchButtonClick()`
    • 内部调用传递进来的 `researchRequestCallback(mTechId)`
  • ⬇️ (回调)
  • ResearchDisplay.cs (UI Controller)
    • 执行 `HandleResearchRequest(string techId)`
    • 构建 `new StartResearchCommand(techId)`
    • 通过 `this.SendCommand(...)` 发送Command
  • ⬇️ (Command Bus)
  • StartResearchCommand.cs
    • `OnExecute()` 方法被调用
    • `this.GetSystem<IResearchSystem>()` 获取研究系统
    • 调用 `researchSystem.StartResearch(techId)`
    • (StartResearch 内部会与ResourceModel交互消耗点数，并与ResearchModel交互更新科技状态)
  • ⬇️ (方法调用)
  • ResearchSystem.cs
    • 执行 `StartResearch(string techId)`
    • 调用 `mResourceModel.ConsumeResource(...)`
    • 调用 `mResearchModel.UpdateTechnologyStatus(techId, ResearchStatus.InProgress)`
    • 更新自身的 `CurrentlyResearching.Value` (BindableProperty)
    • 更新自身的 `CurrentResearchProgressNormalized.Value` (BindableProperty)
  • ⬇️ (方法调用)
  • ResearchModel.cs
    • 执行 `UpdateTechnologyStatus(...)`
    • 修改对应 `Technology` 实例的 `Status.Value` (BindableProperty)
    • 发送 `Model_TechnologyStatusUpdatedEvent` (QFramework Event)
  • ⬇️ (事件/绑定通知)
  • ResearchSystem.cs (再次响应)
    • 之前注册的 `OnModelTechnologyStatusUpdated` (处理 `Model_TechnologyStatusUpdatedEvent`) 被触发
    • 可能触发其自身的C#事件 `OnTechnologyStatusChanged` (如果UI或其他模块监听这个)
  • ⬇️ (绑定通知)
  • ResearchDisplay.cs (再次响应)
    • 之前注册的 `UpdateCurrentResearchInfo` (绑定到 `ResearchSystem.CurrentlyResearching`) 被触发
    • 之前注册的 `UpdateResearchProgressUI` (绑定到 `ResearchSystem.CurrentResearchProgressNormalized`) 被触发
    • 之前注册的回调 (监听 `Model_TechnologyStatusUpdatedEvent`) 触发 `RefreshTechnologyList`
    • UI根据新数据更新显示 (当前研究项目名称、进度条、科技列表状态)
  • ⬇️ (绑定通知)
  • TechDisplayItem.cs (特定项更新)
    • 如果其显示的科技状态发生改变，之前注册的 `UpdateUIBasedOnStatus` (绑定到 `Technology.Status`) 会被触发
    • 如果该项是当前研究项，之前注册的 `UpdateProgressBar` (绑定到 `ResearchSystem.CurrentResearchProgressNormalized`) 会被触发
    • UI项根据新数据更新自身显示

流程二：新的一天开始 (简化版)

  • GameLoop.cs
    • `Update()` 中调用 `mDayNightSystem.UpdateDayCycle(deltaTime)`
  • ⬇️ (方法调用)
  • DayNightSystem.cs
    • `UpdateDayCycle(deltaTime)` 中判断是否到达新的一天
    • 调用 `mGameDataModel.IncrementDay()`
    • 发送 `DayChangedEvent(newDay)` (QFramework Event)
    • 调用 `mCombatSystem.SpawnZombieWaveForDay(newDay)`
    • 调用 `mEventSystem.TryTriggerRandomEvent()`
  • ⬇️ (方法调用)
  • GameDataModel.cs
    • 执行 `IncrementDay()`
    • 更新 `CurrentDay.Value` (BindableProperty)
  • ⬇️ (绑定通知 / QFramework Event)
  • DayDisplay.cs
    • 之前注册的对 `GameDataModel.CurrentDay` 的回调被触发
    • UI更新天数显示
  • CombatSystem.cs
    • 执行 `SpawnZombieWaveForDay(day)`
    • 与 `EnemyModel` 交互添加僵尸
  • GEventSystem.cs (EventSystem.cs)
    • 执行 `TryTriggerRandomEvent()`
    • 与 `EventModel` 交互设置当前随机事件 (`CurrentEvent.Value`)
    • 执行具体 `RandomEvent` 子类的 `Execute()`
    • 发送 `System_RandomEventExecutedEvent`
  • ⬇️ (绑定通知)
  • EventDisplay.cs
    • 之前注册的对 `EventModel.CurrentEvent` 的回调被触发
    • UI更新当前随机事件显示
